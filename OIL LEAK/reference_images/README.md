# JCB Synthetic Reference Images

These are synthetic JCB-specific reference sheets generated for the hydraulic
leak-detection proof of concept.

IMPORTANT:
- These are reference/contact-sheet images, NOT final YOLO training images.
- Do not train YOLO directly on these sheets.
- Antigravity should inspect/crop the individual visual panels into clean images.
- Remove titles, labels, borders, captions and legends from training images.
- Keep RGB and UV references separated.
- Synthetic images must be clearly documented as synthetic.
- UV images simulate a fluorescent leak indication for POC purposes and do not
  prove that ordinary hydraulic oil fluoresces under UV.
